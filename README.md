# Flux Battery

A portable **Flux Networks** battery for **Mekanism**. Power supported machines as a virtual Flux Point, or send surplus charging energy into your network as a virtual Flux Plug.

Requires **Minecraft 1.21.1**, **Java 21**, **NeoForge 21.1.231+ within 21.1**, original **Flux Networks 8.0.0**, **Mekanism 1.21.1-10.7.19.85** and **Kotlin for Forge 5.9.0** on server and clients. Update both sides together.
