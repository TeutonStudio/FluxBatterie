# Crafting and item

[Deutsch](Herstellung) · **English**

![Actual crafting table recipe: four Flux Cores and one Energy Tablet.](https://raw.githubusercontent.com/wiki/TeutonStudio/FluxBatterie/assets/screenshots/wiki-crafting.png)

Craft **one Flux Battery** from four Flux Cores and one Mekanism Energy Tablet in a 3×3 crafting table.

| | | |
|---|---|---|
| empty | Flux Core | empty |
| Flux Core | Energy Tablet | Flux Core |
| empty | Flux Core | empty |

Leave the corners empty. The image shows the recipe actually evaluated by Minecraft, with the resulting battery; it is not a drawn recipe mockup. Modpack datapacks can replace recipes. JEI displays the currently loaded recipe.

In creative mode, the item appears in both **Flux Networks** and **Tools & Utilities**. Each battery occupies its own stack, with a maximum stack size of one.

## Before inserting it

[Choose a network](Network-Selection) and save. Having stored energy does not create a network connection. Ordinary FE item chargers can fill an unconfigured battery's local buffer without enabling automatic network input.

The item tooltip lists stored energy, capacity, network ID and the control for opening configuration. If energy has already been accepted for delivery to a network, the tooltip also lists that pending energy. It survives removal and saving in the item, separately from the ordinary battery buffer.
