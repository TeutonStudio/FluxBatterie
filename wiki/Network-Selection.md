# Network selection

[Deutsch](Netzwerkauswahl) · **English**

![Actual network selection listing the capture world’s two networks.](https://raw.githubusercontent.com/wiki/TeutonStudio/FluxBatterie/assets/screenshots/wiki-network-selection.png)

Open the battery and select **Network selection**, or click the coloured network bar. The server lists only networks it considers accessible to your player.

1. Search by part of a name or a network ID. Name matching ignores case.
2. Use the arrows for longer result lists; each page holds four networks.
3. Click the desired entry. Its network colour sets the battery screen's frame colour.
4. Return to **Settings** and click **Save configuration**.

Long names are shortened on screen. An entry's tooltip contains its full name and ID. The image shows actual networks in the capture world. Search and pagination with a larger sample list were also exercised in the [client checks](Development-and-Tests).

## Disconnect or cancel

**Disconnect** selects “No network selected”. Only saving applies that choice to the battery. **Cancel** and closing the screen discard the current draft. Changing tabs or resizing the window preserves your draft fields.

A deleted or inaccessible network may appear as “Network unavailable / access denied”. Networks and energy are requested when opening the screen, not monitored live. Reopen it after permissions change. See [Permissions and security](Permissions-and-Security) for permanent access requirements.
