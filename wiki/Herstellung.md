# Herstellung und Item

**Deutsch** · [English](Crafting)

![Tatsächliches Werkbankrezept mit vier Flux Cores und einem Energy Tablet.](https://raw.githubusercontent.com/wiki/TeutonStudio/FluxBatterie/assets/screenshots/wiki-crafting.png)

Das Rezept ergibt **eine Flux-Batterie**: vier Flux Cores und ein Mekanism Energy Tablet in einer 3×3-Werkbank.

| | | |
|---|---|---|
| leer | Flux Core | leer |
| Flux Core | Energy Tablet | Flux Core |
| leer | Flux Core | leer |

Die Ecken bleiben leer. Die Abbildung zeigt das tatsächlich vom Spiel ausgewertete Rezept mit dem Batterie-Ergebnis, keine nachgezeichnete Rezeptgrafik. In Modpacks können Datapacks Rezepte verändern; JEI zeigt den jeweils geladenen Stand.

Im Kreativmodus findest du das Item sowohl im Tab **Flux Networks** als auch unter **Tools & Utilities**. Eine Batterie belegt einen eigenen Stack mit maximal einem Item.

## Vor dem Einsetzen

[Wähle ein Netzwerk](Netzwerkauswahl) und speichere die Einstellungen. Ein Energiepuffer allein stellt keine Netzwerkverbindung her. Eine unkonfigurierte Batterie kann von gewöhnlichen FE-Item-Ladern lokal geladen werden; dadurch entsteht noch keine automatische Einspeisung.

Der Item-Tooltip nennt gespeicherte Energie, Kapazität, Netzwerk-ID und die Bedienung zum Öffnen. Er zeigt zusätzlich bereits angenommene, noch ausstehende Netzwerkübergabeenergie, wenn solche Energie vorhanden ist. Diese Übergabeenergie bleibt beim Entnehmen und Speichern im Item; sie ist getrennt vom normalen Batterie-Puffer.
